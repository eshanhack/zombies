# Stahlbunker 1945

Stahlbunker 1945 is an original browser-based, round-based bunker survival FPS. The solo simulation runs entirely client-side and offline after its first successful load. Private one-to-four-player sessions use an authoritative Colyseus server.

The project uses TypeScript, Three.js, Vite, Web Audio, the Pointer Lock API, a hand-built capsule collision system, deterministic fixed-step simulation, and procedural original assets. No proprietary game assets, recordings, names, or layouts are included.

## Controls

| Input | Action |
| --- | --- |
| Mouse | Look |
| Left mouse | Fire |
| Right mouse | Aim down sights |
| Middle mouse or `V` | Melee |
| `W A S D` | Move |
| `Shift` | Sprint |
| Hold `F` | Interact, purchase, repair, or revive |
| Hold/release `G` | Cook/throw grenade |
| `R` | Reload; restart after game over |
| `1` / `2` | Select weapon slot |
| `F1` | Read-only diagnostics and solo verification controls |
| `Esc` | Release pointer lock |

## Local development

Requirements: Node.js 22 or newer and npm.

```bash
npm ci
npm run dev:server
npm run dev
```

The client opens at `http://127.0.0.1:5173`; the authoritative server listens at `ws://127.0.0.1:2567`. Copy `.env.example` to `.env.local` only when a different server endpoint is required.

Append `?seed=12345` to reproduce gameplay RNG. Gameplay never uses `Math.random()`; spawning, crate results, drops, and special-round scheduling use isolated seeded streams.

## Verification

```bash
npm run release:check
npm run gate:p10:server
npm run gate:p9:pacing
npm run gate:p9:network
```

`release:check` runs TypeScript, all automated tests, deterministic asset generation, both production builds, the license audit, the proprietary-name scan, and release-artifact integrity checks. Server/network gates require the local authoritative server to be running.

Phase-by-phase browser observations and measurements are recorded in [BUILDLOG.md](BUILDLOG.md). Original asset provenance is recorded in [assets/CREDITS.md](assets/CREDITS.md). Production setup and rollback steps are in [DEPLOYMENT.md](DEPLOYMENT.md).

## Architecture

- `src/config.ts` — canonical gameplay, presentation, audio, collision, and network tuning.
- `src/shared` — deterministic 60 Hz simulation used by solo and the server.
- `src/game` — Three.js rendering, controller, animation, map, post-processing, and Web Audio integration.
- `server` — authoritative Colyseus room, schema, movement validation, hit rewind, reconnect, and shared state.
- `scripts` / `tests` — deterministic phase gates and regression suite.
- `public/assets/materials` — reproducible original PBR atlases generated by project code.

## Release scope

Release 1 includes the complete solo game, private four-player co-op, and Höllenwölfe special rounds. Gamepad/mobile controls and a second map remain explicitly outside this release.
