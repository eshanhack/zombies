# Asset Credits

Stahlbunker 1945 currently uses no external visual or audio assets.

- Geometry: original procedural Three.js geometry.
- Textures: original runtime-generated Canvas textures.
- Audio: original deterministic 48 kHz Web Audio synthesis. Firearm transients, mechanisms, impacts, footsteps, five zombie vocal families, Höllenwölfe voices, formant-synthesized announcer calls, perk jingles, round/Puppe/game-over cues, electrical beds, room impulse responses, and ambience are all generated in project code; no recordings or external audio files are used.
- UI artwork: original HTML/CSS/Canvas artwork.

Any future CC0 or OFL asset must be listed here with its creator, source URL, license, and retrieval date before it may enter a production build.
