# Asset Credits

Stahlbunker 1945 currently uses no external visual or audio assets.

- Geometry: original procedural Three.js geometry.
- Textures: original runtime-generated Canvas textures.
- Audio: original runtime Web Audio synthesis.
- UI artwork: original HTML/CSS/Canvas artwork.

Any future CC0 or OFL asset must be listed here with its creator, source URL, license, and retrieval date before it may enter a production build.
